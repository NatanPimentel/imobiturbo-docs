# Pedir Conexão ao Corretor

O Imobiturbo.OS permite que administradores gerem um link seguro e temporário para que cada corretor conecte seu próprio número de WhatsApp sem precisar de acesso completo às configurações do sistema.

## Para que serve

Permite que corretores autônomos ou equipes externas leiam o QR Code diretamente de seus próprios celulares ou computadores de forma independente e segura.

## Como fazer

1. Acesse o menu **Conexões** na barra lateral.
2. Localize o canal atribuído ao corretor e clique no botão **Pedir Conexão**.
3. Uma janela será aberta exibindo o link seguro gerado para aquela sessão.

![Modal de Link de Conexão para o Corretor](/img/guias/conexoes/04-link-conexao-corretor.png)

4. Clique em **Copiar Link**.
5. Envie o link gerado para o corretor responsável via WhatsApp ou e-mail.
6. O corretor abrirá o link no navegador e verá a tela de leitura de QR Code simplificada.
7. O corretor fará a leitura com o WhatsApp do próprio aparelho.

## O que acontece depois

- Assim que o corretor conclui a leitura do QR Code, a sessão é ativada instantaneamente.
- O status do canal na sua tela é atualizado automaticamente para **🟢 CONECTADO**.
- As mensagens do corretor passam a ser sincronizadas e distribuídas conforme a configuração da equipe.

## Problemas comuns

- **Link expirou**: O link de conexão gerado possui tempo limite de validade por motivos de segurança. Se o corretor demorar para abrir, basta clicar novamente em *Pedir Conexão* e gerar um novo link.
- **Corretor conectou o número errado**: Caso o corretor leia o código com um número pessoal diferente do corporativo, o administrador pode clicar em *Desconectar* no painel de Conexões e reenviar o link.
