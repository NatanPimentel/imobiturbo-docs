# Tags e Segmentação de Contatos

As **Tags** (etiquetas) são marcadores flexíveis que ajudam a classificar os clientes de acordo com suas preferências, faixa de preço, tipo de imóvel ou origem da captura.

## Para que serve

Permite criar listas segmentadas de clientes para envio de oportunidades direcionadas, acionamento de automações específicas e relatórios de demanda.

## Exemplos comuns de tags no setor imobiliário

- **Tipo de Imóvel**: `#Apartamento`, `#CasaEmCondominio`, `#Comercial`, `#Terreno`.
- **Região**: `#ZonaSul`, `#Alphaville`, `#Centro`, `#Praia`.
- **Perfil de Compra**: `#Investidor`, `#PrimeiroImovel`, `#Permuta`, `#Financiamento`.
- **Origem**: `#InstagramAds`, `#PortalZAP`, `#Placao`, `#Indicacao`.

## Como adicionar tags a um contato

1. Abra a conversa do cliente na **Inbox** ou clique no cliente em **Contatos**.
2. No painel lateral direito, localize a seção **Tags**.
3. Clique em **+ Adicionar Tag**.
4. Digite o nome da tag desejada e pressione `Enter` (ou selecione uma tag já existente na lista de sugestões).
5. A tag será aplicada imediatamente.

## Como remover tags

Para remover uma tag de um contato, basta clicar no ícone de **X** ao lado do nome da etiqueta no painel de detalhes.

## Filtrando contatos por tags

Na tela de **Contatos** ou no **Kanban**, clique no filtro de tags no topo da página e selecione as etiquetas desejadas para visualizar apenas os clientes correspondentes.
