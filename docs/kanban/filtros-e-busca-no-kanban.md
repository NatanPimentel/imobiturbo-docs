# Filtros e Busca no Kanban

A barra superior do Kanban possui filtros rápidos para que você encontre exatamente as oportunidades que precisa trabalhar.

## Para que serve

Permite focar nas oportunidades prioritárias, visualizar o funil de um corretor específico ou segmentar clientes interessados em determinado imóvel.

## Como fazer

1. Acesse o menu **Kanban** na barra lateral.
2. Utilize a barra de filtros localizada no topo do painel:

![Barra de Filtros do Kanban](/img/guias/kanban/03-filtros-kanban.png)

3. Escolha os critérios desejados:
   - **Busca por texto**: Digite o nome, telefone ou e-mail do cliente.
   - **Filtrar por Responsável**: Selecione um corretor específico ou visualize todos da equipe.
   - **Filtrar por Tags**: Selecione uma ou mais tags (ex: *Lançamento*, *Zona Sul*, *Pronto para Morar*).
   - **Filtrar por Período**: Selecione leads criados hoje, nos últimos 7 dias ou em um intervalo personalizado.
4. O quadro atualizará instantaneamente os cartões visíveis.

## O que acontece depois

- Apenas os cartões que atendem a todos os critérios selecionados permanecerão visíveis no funil.
- O contador no topo de cada coluna exibirá a quantidade exata de oportunidades filtradas.

## Dicas úteis

- Para limpar todos os filtros aplicados e voltar à visão completa, clique no botão **Limpar Filtros** ao lado da barra de pesquisa.
